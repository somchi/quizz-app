This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

## Getting Started

First, run the development server:

```bash

yarn install
yarn dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## How to
1. Use yarn for package management not npm
2. To access the participant or audience page /quizzId/participant or /quizzId/audience
3. for since you dont have any ide yet you can use a random text to access the page e.g [http://localhost:3000/123445abcd/audience](http://localhost:3000/12345abcd/audience)
4. To install shadcn components use the command npx shadcn@2.5.0 add (component name)
5. The colors used for the app can be found at the settings folder, you can extend on it, if need be
